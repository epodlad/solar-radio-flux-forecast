# Validation

18 automated tests cover numerical updates, chronology, parsing, gaps and service failure handling. These tests establish software behavior, not forecast accuracy.

Stable-release evaluation must report MAE, RMSE, bias, interval coverage and paired comparisons with persistence and 27-day recurrence. Freeze configuration before evaluating an independent period. Evaluate quiet, active and rapid-change subsets without future-data leakage.

Preliminary development calculations are excluded from this distribution. There is no established operational skill or calibrated interval coverage claim. No original executable or verified legacy reference outputs are available. Archive-vintage hindcasts are not as-issued forecasts.
